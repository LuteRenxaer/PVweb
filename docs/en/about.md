# 关于本文档

这套文档是 **Phira-Vrenxz**（PhirLie）项目的文档站，内容与结构来自 [TeamFlos/phira-docs](https://github.com/TeamFlos/phira-docs)，在此基础上的改动只有：

- 站点框架换成 [VitePress](https://vitepress.dev/)，配色、导航与首页按本作品牌重做；
- 页头、站点名与部分文案改成 Phira-Vrenxz；
- The technical pages are kept as they are (chart standard, UML, respack, events, chart management, build guide).
- The [Changes](/en/changes/) section is written for this fork, based on the project release notes; the upstream "dev incidents" section was removed.
